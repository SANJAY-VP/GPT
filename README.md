# Sitare University Chatbot

### A Contextual Chat Assistant for Sitare University

This project is a **Flask-based Chatbot** that leverages **Sentence Transformers**, **Groq (Llama-3.1-70B)**, and **PostgreSQL** (with the **pgvector** extension) to provide contextually relevant and intelligent answers about **Sitare University**.

## Features

* Retrieval of relevant documents from PostgreSQL using embedding-based similarity search.
* Generation of concise and precise responses powered by **Groq Llama-3.1-70B**.
* User-friendly **Flask** web interface with seamless Q/A chat experience.
* Ability to reset conversation and limit history for clarity.

## Technologies Used

* **Python / Flask** for the web application
* **PostgreSQL** with **pgvector** for embeddings
* **SentenceTransformers** for creating embeddings
* **Groq Llama-3.1-70B** for natural language generation
* **Pandas, Numpy, re** for data processing
* **HTML Templates (Jinja)** for the chat interface

## Setup Instructions

1. Install Dependencies:

   ```bash
   pip install flask psycopg2 pandas numpy sentence-transformers transformers groq
   ```
2. Configure the Database:

   * Install **PostgreSQL** and **pgvector**.
   * Create a database named `my_text_db`.
   * Create a table named `questions` with columns:

     * `id` (SERIAL), `question` (TEXT), `answer` (TEXT), `embedding` (vector)
3. Export Model and Keys:

   ```bash
   export GROQ_API_KEY='your_key_here'
   ```
4. Run the App:

   ```bash
   export FLASK_APP=app.py
   flask run
   ```

## Usage

* Open your browser and navigate to `http://127.0.0.1:5000`.
* Enter questions about **Sitare University**.
* Receive context-relevant answers generated by the system.

## Example Questions

* What is the cost of education?
* How many faculty are there?
* What is the curriculum?
* How can you help me?
